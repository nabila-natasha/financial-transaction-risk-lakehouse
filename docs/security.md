# Security

## 1. Data Classification

PaySim is synthetic benchmark data and does not represent
real customer transactions.

Frankfurter provides public exchange-rate data.

## 2. Secrets

No credentials, API keys or connection strings are committed
to GitHub.

## 3. Identity

Azure access follows least-privilege principles where
practical.

## 4. Portfolio Limitation

This project does not claim production banking security,
fraud-detection certification or regulatory compliance.
